# Imposter

Deutsches Wortspiel auf einem gemeinsamen Handy. Spielerzahl (ab 3), eindeutige Namen und eigenes Wort eingeben. Genau ein Imposter wird mit `crypto.getRandomValues` gleichverteilt ausgewählt. Das Handy wird für die verdeckte Rollenanzeige weitergegeben. Anschließend diskutieren und gemeinsam abstimmen, dann aufdecken.

Kein festes Spielerlimit; die praktische Grenze hängt vom Gerät ab. Namen, Wort und Rollen bleiben im Arbeitsspeicher des Browsers. Neuladen verwirft die Runde. Wer das Wort eingibt, kennt es bereits – idealerweise übernimmt das eine Person, die nicht mitspielt.

## Starten

`dist/index.html` im Browser öffnen oder den Ordner `dist` mit einem beliebigen statischen Webserver bereitstellen. Keine Installation und kein Build nötig.
